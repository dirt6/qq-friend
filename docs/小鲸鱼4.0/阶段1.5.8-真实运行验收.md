## 三、`tokens: null` 的最终结论（实测）

```
$ dsh --json -
{"type":"final","text":"…"}
{"type":"session","sessionId":"…"}
{"type":"status","phase":"turn_start","turn":1}
{"type":"status","phase":"step_start","turn":1,"step":1}
{"type":"status","phase":"step_end","turn":1,"step":1}
{"type":"status","phase":"turn_end","reason":{…}}
```

**`status` 里没有任何 usage 字段**（dsh 0.2.1-rc.5）。

所以 DSH 调用的 token **拿不到**，`tokens: null` 是如实反映，不是 bug。

**影响**：账本会低估 DSH 的用量（自主活动现在全走 API，暂不受影响；将来迁到 DSH 后会）。

**要精确统计**，只能解 `data/dsh-home/sessions/**.jsonl.zstd`——另一个题目。
