## 四、`noreply` 状态：要你定

**它是什么**（`orchestrator.js:1761`）：

```js
// 收尾：发过话 = done；没发 = noreply（这是正常选项）
const status = session.error ? 'error' : (session.sent.length > 0 ? 'done' : 'noreply');
```

**= 会话正常结束，但她没说话**（看了消息，决定不回）。不是失败、不是异常。

**现状**：16 个，总共约 1.6 MB。

**我的建议：暂时不归档**。理由：
1. 你明确说"只归档 done"
2. 只有 16 个，省 1.6 MB 不值得扩大规则
3. 保守优先

**但如果你觉得它们是"已完成的记录"、该和 done 一起处理**，改一行条件就行。
