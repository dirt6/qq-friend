### 3.2 2.6-A：误分类诊断（已完成）

**发现的问题**：
```js
// plugins/autonomous/index.js:1633（旧）
if (decision.goal) setCompanionGoal(String(decision.goal), { source: 'autonomous' });
```

**`decision.goal` 是 Action Objective（这次动作想干什么），被直接写成长期 Goal。**

**生产数据印证**：`round-42574042` 一轮 3 个 Action → 4 秒内建了 3 条 Goal（含 1 条 **failed** 的动作）。

**机主定的原则**：
> 只有跨越单次自主活动、具有持续关注价值的方向，才能成为 Goal。
> 单次活动产生的具体行动默认不持久化为 Goal；需要以后继续处理时，才考虑记录为 Pending。
