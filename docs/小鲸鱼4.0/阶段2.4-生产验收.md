## 五、一个必须说明的行为：结算时机

**现在 `pending` 还没被结算**（`status` 仍是 `pending`，`updatedAt` 还是迁移时间）。

**这是正确行为，不是 bug。**

`settleChatPending()` 的**唯一调用点**是 `runSession` 开头：

```js
// plugins/autonomous/index.js:1280
const st = readState(STORE, ...);
try { settleChatPending(st); } catch (e) { ... }
```

**也就是说：结算发生在「下一次自主活动开始时」，不是聊天时。**

手动预演确认条件已满足：

```
待办: 等老大回应，看他怎么说
at:   2026/11/1 13:59:05
最后一次会话文件修改: 2026/11/1 15:28:00
是否 > at + 90s: 是（应该结算）
```

**所以 16:59 那轮自主活动一启动，它就会被结算。** 这是第二轮要验的核心。
