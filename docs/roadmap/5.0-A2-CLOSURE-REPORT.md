## 二、输入契约

```js
{
  now?: number|string,                 // 可选；不读系统时钟
  conversation?: {
    status?: 'open'|'closed'|'paused',
    lastEffectiveAt?, summary?, nextTopic?,
    userRequestedContinue?, userEnded?, userBusy?,
    allowNextOpening?
  },
  messages?: [{ role:'user'|'assistant', text, at?, intent?, answered?, requestId? }],
  unresolvedRequests?: [{ id?, text, kind?, askedAt? }],
  purpose?: A1Output | Candidate[],    // 只作上下文
  summary?, nextTopic?
}
```

非法顶层/字段类型 → `{ok:false,code:'INVALID_INPUT'}`；坏消息跳过并计数；输入不修改。

## 三、输出契约

```js
{
  ok: true,
  decision: 'continue'|'close'|'hold'|'undetermined',
  reason,
  unresolvedRequests: [{id,text,kind,askedAt,explicit}],
  summary: '',                 // 不自动生成，仅接受调用方已有摘要
  nextOpening: '',             // 可选，可为空
  uncertainties: [{code,detail}],
  diagnostics: { messagesRead, skipped, userMessages, assistantMessages, order,
                 purposeProvided, purposeCount, lastRole, lastUserIntent, flags,
                 idleMs, lastEffectiveAt }
}
```

## 四、判定规则

| 情况 | decision | reason |
|---|---|---|
| 最后用户消息是问题/求助，尚未回答 | continue | user_asked_question / user_needs_help |
| 问题已答，但用户未确认 | hold | answered_but_awaiting_user_ack |
| 用户明确说继续 | continue | user_requested_continue |
| 未解决请求（显式/answered=false/无回答） | continue | unresolved_requests |
| 用户明确结束 | close | user_ended |
| 用户只感谢/简短确认 | close | user_thanks / user_acknowledged |
| 用户没有回复 | hold | user_has_not_replied（不判同意结束） |
| 双方重复表达、无新信息 | hold | repeated_content_no_new_info（不自动告别） |
| 用户有实质新消息、未回复 | continue | substantive_user_message_awaiting_reply |
| 空对话/只有 assistant | undetermined | empty_conversation / no_user_message |
| 无法判断 | hold/undetermined | no_clear_closure_signal |

- 明确问题/求助优先于任何收尾；
- 未解决请求优先于感谢/时间/轮数；
- 没有新内容 ≠ 必须发送告别；
- 用户没回复 ≠ 同意结束；
- 用户明确结束才 close（感谢/确认也可 close，但不等于 Goal 完成）；
- 无时间信息不做超时推断；乱序消息按时间排序并标 `message_order`；
- `nextOpening` 仅 close/hold、无未解决请求、用户未结束时，取 `nextTopic` 或 A1 高置信候选标题；否则为空；
- `summary` 不自动生成。

## 五、A1 关系

- A1 候选**不强制** continue/close；只影响 `nextOpening`（confidence ≥0.5）与诊断；
- A1 低置信不用于 nextOpening，标记 `low_purpose_confidence`；
- A1 无候选 → nextOpening 为空；
- A1 `ok:false`/非法结构 → `purpose_unavailable`/`purpose_invalid`，不影响对话判定。
