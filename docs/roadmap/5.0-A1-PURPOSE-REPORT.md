## 二、输入契约

```js
{
  now?: number|string,        // 可选；不读系统时钟
  goals?: Goal[],             // 只读现有长期方向
  pending?: Pending[],        // 只读现有事项
  topics?: Topic[],           // 只作为上下文，不生成候选
  materials?: Material[],     // 聊天/外部/伙伴兴趣的结构化材料
  rounds?: any[], activities?: any[], messages?: any[] // 保留，不写
}
Material = {
  id?, text, owner? | declaredOwner? | authorRole?,
  intent?: 'long_term'|'one_off'|'interest'|'chat'|'observation',
  explicit?: boolean, epistemic?: 'explicit'|'observed'|'inferred',
  dedupeKey?
}
```

非法顶层/字段类型 → `{ok:false, code:'INVALID_INPUT'}`；单条坏数据跳过并计数，不崩溃。

## 三、输出契约

```js
{
  ok: true,
  candidates: [{
    candidateId, kind, title, owner, epistemic, longTerm,
    confidence, value, urgency, risk, score,
    evidence: [{type,id,text,strength}],
    sourceRefs, reasons: [], uncertainties: [],
    needsConfirmation
  }],
  noAction: boolean,
  reason: 'has_candidates'|'no_worthwhile_work'|'no_input',
  uncertainties: [{code,detail}],
  diagnostics: { goalsRead, pendingRead, materialsRead, topicsRead, skipped, deduped }
}
```

无候选是合法结果；不生成 `no_action` 伪候选。

## 四、规则

| 输入 | 输出 |
|---|---|
| 用户 `user_directed` Goal | `advance_goal`，owner=user，explicit，longTerm=true |
| 用户一次性请求 | `continue_pending`，longTerm=false，`one_off_not_long_term` |
| 伙伴兴趣 | `interest_exploration`，owner=partner，要求历史证据 |
| 第三方目标/内容 | 最多 `record_only`，owner=external，绝不 user/advance_goal |
| 仅外部观察 | `record_only` |
| 普通聊天/Topic | 不产生候选 |
| 仅推断 | 低置信度、`needsConfirmation`，longTerm=false |
| 归属冲突 | **丢弃该候选** + `conflicting_owner`，不猜、不升级 |
| 来源缺失 | 不生成候选 + `owner_unknown` |
| 重复材料 | 按 subject 去重，合并证据，`diagnostics.deduped` |
| 空输入 | ok/noAction/no_input |

排序：`score = confidence*0.55 + value*0.25 + urgency*0.2 - risk*0.15`，再按 kind 优先级、candidateId 稳定排序。
