# 5.0-E1：持久化执行状态机验收报告

> 实现：`src/autonomous/execution-state.js`、`src/autonomous/execution-store.js`
> 专项：13/13；仅临时目录，无生产路径
> 结论：**E1 PASS（隔离）**

## 一、状态

`decision_recorded / authorization_pending / authorized / started / succeeded / failed / unknown / cancelled`

合法迁移：
- decision_recorded → authorization_pending / authorized / cancelled
- authorization_pending → authorized / cancelled
- authorized → started / cancelled
- started → succeeded / failed / unknown
- unknown → succeeded/failed **仅 reconcile + evidence**
- failed → authorization_pending 需 `retry_authorized` 且未超限
- succeeded/cancelled 终态

## 二、持久化

- 调用方必须显式传 file；无默认生产路径；
- `withFileLockAsync` + `writeFileAtomic`；
- `recordReceipt` 按 receiptId 幂等；
- `apply` 按 eventId 幂等；
- 审计 history/audit 版本；
- `recover` 将 started → unknown（process_restart），不自动 failed/succeeded；
- `reconcile` 必须证据；
- pause/resume 持久化。

## 三、测试

13/13：迁移/非法跳跃/unknown 对账；failed 重试授权与上限；record 幂等；event 幂等；authorization 绑定 receipt/plan/expiry；started 恢复 unknown；unknown 不能普通 apply；重启读取；pause/resume；不存在/终态拒绝；JSON 完整；无 file 拒绝。

## 四、遗留

1. 授权 token 的签名/来源未验证（只校验字段与过期）；
2. file 路径安全由调用方负责；
3. 未接协调器/生产；
4. 执行结果 unknown 的人工对账流程待 E2/E4。
