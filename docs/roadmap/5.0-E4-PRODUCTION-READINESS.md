# 5.0-E4：生产接入准备方案

> 时间：2026-11-05
> 性质：只提交准备方案；**未部署/未重启/未配置/未 tick**
> 结论：隔离层 E1–E3 通过；生产接入需 E5 单独授权

## 一、分级灰度

| 阶段 | 允许 | 禁止 |
|---|---|---|
| G1 只读自主运行 | A1/A2/A3/A4、B、C 决策；不执行；不发送 | 模型/工具/写入/发送 |
| G2 受控记忆写入 | 仅 D 路由白名单领域；小范围 | 日记原文、Goal/Pending 自动改 |
| G3 主动分享/外部行为 | 明确发送授权、频率/预算/白名单 | 自动发帖/评论/无限重试 |

## 二、预算与模型

- 沿用 autonomous 当前配置：单轮最多 6 次模型调用、maxInputTokens 8000、月度预算 5 元（以现场配置为准）；
- 协调器不新增模型调用；A1–C 纯逻辑零模型；
- 单轮 execution 最多 1 个 Action（`maxSteps=1`）；
- 超时默认 30s；超时→unknown，不自动重试；
- 每日/每月成本由 token ledger 观测；达到预算即 stop，不续借；
- 禁止为验证而提高预算/调度。

## 三、权限

- executor 必须是白名单实现，禁止任意 shell/路径/外部请求；
- 工具参数必须由执行层校验；协调器只传 `activity/authorization`；
- C `share_now` 不授权发送；发送层需再次检查用户设置/频率/白名单；
- D 只路由，域模块唯一写者；Memory Hub 只读；
- 授权 token：receiptId + planHash + authorizedBy + expiresAt + scope；缺失/过期/篡改拒绝。

## 四、暂停/审计

- `execution store.pause(reason)` 持久化；协调器在授权后、started 前检查；
- 进程重启 `recover()`：started → unknown，不自动成功/失败；
- 审计：receipt、state history、audit、eventId、时间、错误/证据；
- unknown 必须人工/外部证据 `reconcile`，禁止自动改写；
- 生产 hash 前后对比，异常停止。

## 五、回滚

- 代码回滚版本：上一稳定 tag/commit（执行前核验）；
- 配置/快捷方式备份；
- 数据只读备份；禁止 reset/删 Session/清 Goal/Pending/日记；
- 回滚后验证 3210/OneBot/ChatStore/autonomous，再恢复灰度；
- 失败保留日志、状态文件、hash 与授权记录。
