# 4.0 测试隔离审计与统一工具（P1）

> 时间：2026-11-04
> 性质：只读扫描 + 工具实现；未改生产记录
> 范围：全部 `test/*.mjs`（172 个，含辅助/worker）

## 一、事故根因

`test/autonomous-test.mjs` 只给 `appendDiaryLine` 传了临时日记 root，但 writer 的 pending/idem 路径来自 `DATA_DIR`（`src/diary/writer.js:51`）。测试模块在导入插件前未设置 `QQ_AGENT_DATA_DIR`，于是 21:39:59 写生产 pending/idem（2 条既有 11-03 测试记录被完成/刷新）。

**修复**：导入插件前设置临时 `QQ_AGENT_DATA_DIR`，并动态 `import()`（commit `1248d35`）。

## 二、统一隔离工具

新增：

| 文件 | 作用 |
|---|---|
| `test/_isolation.mjs` | `createIsolationRoot`（临时 data/diary/config）、`assertIsolatedPaths`（拒绝生产路径/越界）、`assertTestEnv`、`cleanupIsolation` |
| `test/_isolation-preload.mjs` | `node --import` 预加载：在任何数据模块前建立临时根、写最小 config；退出时清理 |
| `test/_isolation-probe.mjs` | 子进程探针：验证 env、模块 DATA_DIR、写入/拒绝 |
| `scripts/test-isolation-audit.mjs` | 静态扫描测试入口，输出 no-marker / 硬编码生产路径 / 直接生产写 |

关键设计：

1. 预加载在**测试主模块之前**执行，避免 Node 模块缓存生产 `DATA_DIR`；
2. `assertIsolatedPaths` 解析 `..` 后仍拒绝生产根；
3. 子进程通过继承的隔离 env 启动；探针无 env 时拒绝；
4. 临时根 config 固定 diary root；所有写入应位于根内；
5. 清理失败返回明确错误，不静默；
6. 预加载不导入 `src/`，避免自身触发路径缓存。

## 四、回归接入

`scripts/run-regression.ps1`：

- 非 diary 测试默认 `node --import ./test/_isolation-preload.mjs`；
- diary 测试仍走 `run-diary-test.mjs`（其自带 DIARY_TEST_TMP）；
- 6 个只读生产检查测试显式跳过预加载；
- 新增 `test-isolation-guard-test` 纳入全量。

## 五、未完成/限制

- 3 个高风险 legacy 测试尚未改造，仍**不要在非隔离环境直接运行**；
- 预加载的临时 config 只固定 diary root，不复制生产 config；需要特定配置的测试仍自行写 config；
- Windows 下生产 ACL/浏览器等 UNKNOWN 不影响隔离工具；
- 预加载清理发生在进程退出；强制 kill 时可能残留临时目录（系统 temp，可人工清理）。
