## 一、结论

**4.0 行为读取已统一到 Memory Hub；`members`/consolidation 保留 MemoryStore 是明确例外。**

理由：`members`/consolidation 不是纯展示读，而是**写前读**：

- 需要 `lastConsolidatedAt`、成员身份、`updatedAt`；
- 需要做身份解析/回写、替换成员、记录整理时间；
- Hub 是只读视图，不能提供这些写状态；
- 强行接 Hub 会引入“读视图当写状态”的风险。
