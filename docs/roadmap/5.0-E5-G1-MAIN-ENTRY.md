### 接口

- `POST /api/g1/run`：`x-console-token` + `x-g1-nonce`；仅未暂停、未运行、nonce 未用、未用过本 resume tick 时执行。
- `POST /api/g1/pause`：body `{paused:true}` 暂停；`{paused:false}` 为恢复（为 G1 运行所必需，文档化；不是新阶段）。
- `GET /api/g1/status`：只读，无副作用。

### 安全

- 服务仍由全局 `listenExclusive(..., '127.0.0.1')` 绑定回环；
- `/api/*` 全局 `authorize` + `originAllowed`；G1 额外要求非空 server token 且仅接受 `x-console-token` 头（不接受 URL token）；
- nonce 16–128，SHA256 后入 state；一次性/重放拒绝；
- 每个 resume 周期最多一次 tick（`tickUsed`），并发 `run` 通过锁 + running/tickUsed 只允许一次；
- pause 状态持久化；启动默认 paused；state 损坏/读取失败 fail-closed；
- run 在快照后、A1 后、A3 后、最终写 receipt 前检查 paused；暂停则返回 423，不写成功 receipt；
- 审计仅 `data/5.0-g1/state.json`、`g1-audit.ndjson`、`g1-receipt.json`、`g1-audit.json`；
- 无 executor/model/tool/business write/send；无自动调度。
