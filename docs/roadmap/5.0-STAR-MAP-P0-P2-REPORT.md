## 一、已完成

### P0 数据层（零写盘）

| 文件 | 作用 |
| --- | --- |
| `src/diary/parse.js` | 日记 Markdown → `{day,title,entries}` 的唯一解析；`/api/diary` 与星图共用 |
| `src/star-map/projection.js` | 纯函数：条目 → 节点（权重/亮度/同名簇）、边（同日/同心情/同关键词/来源） |
| `src/star-map/index.js` | 读盘、按文件指纹缓存、单节点详情、体检统计 |
| `src/routes.js` | `GET /api/star-map/graph` / `node` / `stats`；`/api/diary` 改用共享解析 |

- 节点 id：`diary:<day>:<sha1(content).slice(0,8)>`（重复内容追加 `-2`）。
- 权重按方案 §4.3：长度 + `[重要]` + 同日条数分位，clamp 0.3–1。
- 边上限：每节点 6 条（同日 3 / 心情 2 / 关键词 1），全局 2000；没有边就不编。
- 全记忆模式：其他层作为背景星尘，亮度 ×0.35，`learned.sourceDay` 连“来源边”。
- 不写日记、不写记忆、不改 Memory Hub。

### P1/P2 前端（Canvas 2D，零框架）

- 日记页改为**左星图 / 右日记**：中间可拖动分栏、右栏可收起（状态存 localStorage）。
- 星空：时间旋臂，日期序号 → 半径；同日条目半径相同、角度按哈希 ±8° 散开；重要条目金环，今天偏青。
- 交互：拖动旋转、滚轮缩放、双击复位、悬停提示、点击定位右栏条目。
- 搜索：命中做种子，沿边亮 1–2 跳（多路径叠加、阈值 0.12、上限 80 节点），边浮现（1 跳实线 / 2 跳虚线）。
- 筛选：只看重要 / 只看今天（其余变暗不消失）。
- 联动：点星展开对应那天并高亮；右栏保存/删除后派发 `diary-changed` 自动刷新星图；右栏悬停条目光亮对应星。
- 体检面板：断档、空白天、平均条数、最密一天、重要占比、心情词频。
- 导出「今晚的星空」PNG（带日期/条数/指纹前 8 位，导出前提示含原文摘要）。
- 空态：“还没有第一颗星”；格式异常/空白天不产生节点，但体检会报告。

### 日记编辑

按方案附录 B 的决定：**复用现有 `POST /api/diary/add|edit|delete`**，不新增写接口；并发与备份沿用统一 writer。

## 四、怎么用

重启面板后进入「日记」tab：左边星空、右边日记。

- 空白处双击复位；`Esc` 清除选中与搜索。
- 「全部记忆」打开后，经验/印象/计划变成背景星尘；点它们不会跳转（只读投影）。
- 体检/导出按钮在星图顶部工具栏。

## 五、2026-11-07 视觉规则 v2

- **银心**：`[非常重要]` 的日记，黄白、第一亮，贴中心；越热越靠内。
- **旋臂**：`[重要]` 的日记，一个话题一条旋臂，黄白、第二亮；没并进话题的归「其他」旋臂。
- **旋臂之间**：`[一般]` 日记 + autonomous/round 活动，按话题分色（调色板可循环，颜色可重复），
  同话题有连线，第三亮。
- **小行星带**：心情「记住了」的日记，绕在最外圈。
- **提及热度**：话题成员数 + 经验 hits 命中 → 决定半径与亮度；越被提到越靠内、越亮。
- **话题**：共词图 + 并查集在投影层临时聚类，只用于渲染分组；不落盘、不建新存储、不改 Memory Hub
  （始终是原来那套 Memory Hub）。
- **自转**：约 5 分钟一圈；拖动时暂停，松手继续。

同轮修复：Electron 不支持原生 `prompt/confirm`，日记「改/增/删」等按钮会静默失败；
已全部改为项目内 `uiPrompt/uiConfirm`。本机协议端是 NapCat，不再对齐 SnowLuma 协议栈。

## 六、2026-11-07 视觉规则 v3（星座）

- **银心**：「非常重要」固定在最中心，不参与话题。
- **旋臂**：「重要」沿螺旋旋臂排布；旋臂线是螺旋（不是直线）。
- **一般 / autonomous / round**：归入所属话题，贴着同话题旋臂两侧，按话题轮换星座形状
  （弧 / 锯齿 / 环 / 波 / 螺旋 / V）；同话题连线**默认常显**，激活时整体高亮。
- **小行星带**：心情「记住了」的日记放最外圈，**不分话题、不连任何线**。
- **颜色可重复**（调色板循环）。
- **无话题兜底**：共词聚类没收进去的，按内容就近归入已有话题；仍不沾边的，
  再归到「日常 / 技术 / 影视游戏 / 学习 / 画画」几个兜底类目；最后才是「其他」。
- 旧 autonomous round：删除 5.0（2026-11-04）之前的 51 条，保留 4 条；
  删除前备份到 `data/backups/autonomous-pre5-*.json`。

## 七、可编辑星图（2026-11-07）

- 「编辑」按钮进入编辑模式：拖动星星 → 放到旋臂线 = 重要 + 归入该话题；
  放到银心 = 非常重要；放到某话题星座 = 改话题归属。
- 重要级写回日记原文（`[重要]` / `[非常重要]`，走统一 writer，带 `.trash` 备份与审计）。
- 话题归属 / 自定义旋臂 / 被删旋臂存在 `data/star-map-overrides.json`（展示层覆盖；
  不改 Memory Hub 的记忆内容，也不新增记忆层）。
- ＋旋臂：手动添加空旋臂；点旋臂线选中后按 Delete 删除（成员回到「其他」，日记不删）。
- 改日记后星图会刷新：面板保存派发 `diary-changed`；外部改文件则切回日记 tab 时重新拉图
  （服务端按文件指纹缓存，未变不重算）。
