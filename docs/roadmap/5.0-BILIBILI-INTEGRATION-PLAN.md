## 二、能力分层

### B1 只读详情（完成）

- 公开榜单/搜索；
- 视频详情：标题、UP、简介、统计；
- 热评：前 N 条，带 rpid/root/parent；
- 入口：`bili_detail`。

### B2 视频总结（完成）

- 基于详情 + 热评 → 模型总结；
- **不读取字幕/正文/画面**；
- 输出必须带信息边界；
- 入口：`bili_summary`。

### B3 写操作

| 动作 | 状态 |
|---|---|
| 评论 | ✅ 预览；`confirm:true` 才发；每小时 3 条 |
| 回复热评/楼中楼 | ✅ `replyTo` / `root` |
| 分享到当前聊天 | ✅ `bili_share`（只发链接，不是站内转发） |
| @ 指定人 | ✅ `mention`；`owner`/`me` = 泥土如是说（UID 507695674） |
| 自动评论 | ❌ 未开 |

写操作要求：
- `data/bili-auth.json` 有效；
- 默认预览，不确认不发；
- 失败/未登录明确拒绝；
- 不自动重试 UNKNOWN。

### B4 收件箱（只读完成）

- `bili_inbox` 读取“回复我的/@我的”；
- 返回 target/root/parent，可直接喂 `bili_comment` 的 `replyTo`；
- 未接自动轮询、自动回复。

## 三、架构

```text
Chat tools
 ├─ bili_detail / bili_summary
 ├─ bili_comment（评论/回复/@）
 ├─ bili_share（当前聊天）
 └─ bili_inbox（只读）
Runtime（未来空闲）
 ├─ BiliReadAdapter
 ├─ BiliWriteAdapter
 ├─ QQ G3
 └─ Memory Hub
```

- 不建第二套记忆；
- 不自动循环；
- 未来空闲需要：预算、去重、静默时段、B站主人映射（已加：泥土如是说/507695674）。

## 四、实施顺序

1. B1 详情/热评（✅）
2. B2 视频总结（✅）
3. B3 评论/回复预览（✅）
4. B3 分享/@（✅ 手工）
5. B4 收件箱（✅ 只读）
6. 空闲自动评论/回复（未开；需调度+配额+确认策略）

## 五、安全边界

- Cookie 不进 Git/日志/报告；
- 评论/回复必须明确确认；
- 不绕过验证码/风控；
- 公开评论默认不自动回复；
- 账号异常立即暂停，不重试。
