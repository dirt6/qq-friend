## 一、实现

新增 `src/autonomous/memory-governance.js`：

- `canReadDomain({requester,domain,purpose})`：chat/autonomous/core/admin 经 Memory Hub/Core 读取；无 purpose 拒绝；**不读文件、不写**。
- `governMemory({now,intents,existing})`：校验/路由写入意图，输出 accepted/rejected/corrections/lifecycle/uncertainties。
- 写入只返回 `routedTo` 原领域，不执行写入；Memory Hub 不是平行写入系统。

## 二、治理规则

### 读取

- 只允许已知 requester/domain，且必须有 purpose；
- ChatStore 仍是聊天历史唯一维护者（chat 写入拒绝 `chatstore_owned_read_only`）。

### 写入

- domain：learned/diary/memory/companion（chat 只读）；
- 必填 source/owner/epistemic/content（archive/expire 例外）；
- inferred 必须有 evidence；external 必须有 source；
- owner/epistemic 非法拒绝；at 非法拒绝；
- 版本冲突拒绝，不覆盖。

### 纠正（D3）

- `correct` 必须显式 target；
- 目标存在：`oldPreserved:true`，保留历史；
- 目标不存在：`targetResolved:false`、`historicalUnresolved:true`，不按文本猜测；
- 用户已纠正内容（`explicitCorrected`/user corrections）不能被 inferred 覆盖：`correction_protected`；
- corrections 与 epistemicType 正交；
- 现有 `historicalUnresolved` 不清除，输出 preserved 标记。

### 生命周期（D4）

- 重要日记 archive → 拒绝；
- 临时事项可 expire，输出 `goalCompleted:false`；
- 非临时 expire → 拒绝；
- Goal 生命周期不由 Hub 改 → 拒绝；
- 可变事实/推断写入 → `needsReview:true`；
- 旧数据缺 version/corrections → legacy 标记，不重写。
