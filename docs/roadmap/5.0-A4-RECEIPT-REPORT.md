## 一、实现

新增 `src/autonomous/receipt.js`，纯逻辑、无 I/O/模型/发送/系统时钟/随机。

输入：A1 Purpose、A2 Closure、A3 Activity、`now`、可选 `inputRef/summary/decisionVersion/existingReceipts`。
输出：`receipt`（稳定 `receiptId`、版本、`createdAt`、输入引用、Purpose 候选、Closure、Activity、拒绝原因、风险/预算/确认、来源 ID、不确定性、execution 契约）。

- `receiptId` 由 Purpose IDs + Closure + Activity + rejected 的内容哈希生成；时间不参与 → 同一决策稳定、不同时间可重复识别。
- `existingReceipts` 命中 → `duplicate:true`，原回执原样返回，不产生第二份。
- `createdAt` 严格取输入；缺失/非法 → `MISSING_TIME`。
- A1/A2/A3 缺失/`ok:false` → 明确失败，不伪造回执。

## 二、执行状态契约

`EXECUTION_STATES`：decision_recorded / authorized / started / succeeded / failed / unknown / cancelled。

- 本批只生成 `decision_recorded`，`authorized=false`，`history=[]`；
- 不生成 `executedActivity`、执行结果、发送/写入字段；
- `canTransitionExecution` 只定义迁移：decision→authorized/cancelled；authorized→started/cancelled；started→succeeded/failed/unknown；unknown→succeeded/failed；failed→authorized；succeeded/cancelled 终态。
- 后续执行层必须重新授权/检查，不能把 receipt 当执行授权。
