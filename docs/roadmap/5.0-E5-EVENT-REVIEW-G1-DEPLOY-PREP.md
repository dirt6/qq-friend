| 项 | 结论 |
|---|---|
| 鉴权 | 路由独立要求非空 `server.token` + `x-console-token`，拒绝 URL token；全局 `/api` 仍要求 authorize |
| Origin | 全局 `originAllowed`：Host 必须回环，Origin/Referer 必须同源；服务 `listenExclusive(...,'127.0.0.1')` |

| 重启 | state.running → status paused=true/running=false；unknown_after_restart；不自动恢复 |
| executor/model | G1 service 只 import A1–D；无 coordinator/executor/LLM/工具/发送；审计仅 `data/5.0-g1` |
