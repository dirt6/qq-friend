## P0 授权完整性

`src/autonomous/authorization.js`：

- HMAC-SHA256，`keyId` 支持轮换；密钥由调用方提供，无默认密钥、不写日志；
- payload 绑定 receiptId、planHash、actionType、target、paramsHash、authorizedBy、scope、issuedAt、expiresAt、nonce；
- 验签使用 timingSafeEqual；校验过期、未来签发、撤销、重放/重复消费、绑定字段/参数哈希；
- nonce ledger（可选文件）跨实例防重放；损坏 ledger **fail-closed**；
- 密钥丢失/未知 key/签名不符 → 拒绝；
- 授权 token 不包含明文密钥；不作为普通参数传递。

## P1 执行结果判定

`src/autonomous/execution-result.js`：

- timeout/throw/无 outcome → **unknown**，不按异常类型猜 failed；
- `ok:false + sideEffect:'none'`（执行器明确证明未发生）→ failed；
- `sideEffect:'occurred'` 或未声明 → unknown；
- `ok:true` → succeeded；
- coordinator 已改为该语义：抛异常不再直接 failed。

## P2 执行器独立闸门

`src/autonomous/executor-gate.js`：

- 每次工具调用独立校验：工具白名单、JSON Schema、actionType/target/params 与授权一致、paused、预算、次数上限；
- 未知工具/未知参数/额外字段 → 拒绝；
- 上游 selectedActivity/Receipt/模型输出不能替代闸门；
- coordinator 在提供 `executionPlan` 时调用闸门；生产接入必须提供 plan/tools。
