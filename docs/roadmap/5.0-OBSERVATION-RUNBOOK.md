## 三、异常处置

| 现象 | 处置 |
|---|---|
| G1 不是 paused | 立即用 G1 pause API/维护窗口暂停；不继续 |
| Runtime 不是 paused | 立即 pause；检查 state 是否损坏 |
| G2/G3/readonly enabled | 立即 features=false + pause；查最近调用 |
| G3 sending>0 | 不重发；按 journal/OneBot 对账 |
| G3 unknown 新增 | 不自动重发；记录原因，人工确认 |
| started>0 | 不重放；用 execution store 对账，保持 unknown |
| OneBot 断线 | WARN；恢复后观察，不触发发送 |
| token 文件缺失/损坏 | fail-closed；不要临时放宽 |
