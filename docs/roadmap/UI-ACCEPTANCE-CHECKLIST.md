## 第五步：如果出问题

| 现象 | 可能原因 | 怎么回滚 |
|---|---|---|
| 页面白屏 | JS 报错 | 看 DevTools Console |
| 左栏挤成一团 | CSS 改坏 | `git revert d589af3` 只回滚样式 |
| 某个 tab 点了没反应 | `switchTab` 找不到 `view-xxx` | 检查 `index.html` 的 id |
| 二维码显示糊 | 源图只有 147×147 | 改走 6099 WebUI 方案 |
| 记忆列表报错 | 后端异常 | 看 `data/dsh-gateway.log` |

**回滚命令**（按影响面从小到大）：

```
git revert d589af3   # 只回滚 impeccable 样式修复
git revert b285fe2   # 回滚 R7-B 运维页
git revert 163b34e   # 回滚 R7-A 记忆管理
```

## 验收结论怎么写

**这次验收的结论只有三种**：

| 结论 | 条件 |
|---|---|
| **PASS** | 三页全部渲染正常，A1~E7 关键项通过 |
| **PARTIAL** | 部分页面正常，部分有 bug |
| **FAIL** | 页面不可用（白屏/报错） |

**⚠️ 无论哪种，都必须记录"哪几项真的看了、哪几项没看"。**
**没看过的项不能因为"其他项通过了"就默认通过。**
