## 一、实现

输入：发现（标题/摘要/来源/可靠性/相关/价值/敏感/指纹）、用户设置（关闭自主分享/勿扰/屏蔽来源/话题）、A2 Closure、最近分享、限制（cooldown/maxPerDay）。

输出：`decision`（share_now / save_for_later / record_only / do_not_share / undetermined）、reason、fingerprint、duplicate、similarTo、needsConfirmation、`sendAuthorized:false`、risk、uncertainties、diagnostics。

**share_now 不是发送授权。**

## 二、规则

- 用户关闭/勿扰 → do_not_share；屏蔽来源/话题 → do_not_share；
- 敏感（>=0.7）→ do_not_share；
- 重复（fingerprint/相似度 >=0.6 同来源，cooldown 内）→ record_only；
- 频率超限 → save_for_later；
- A2 continue/hold 或用户求助/忙 → save_for_later（不插入）；
- 来源不可靠 → record_only；低相关/低价值 → record_only；
- 高相关+高价值+可靠 → share_now；
- 中等 → save_for_later；
- 来源可靠性冲突/缺内容 → undetermined；
- 指纹含标题+摘要+来源；中文双字片段用于轻微改写去重。
