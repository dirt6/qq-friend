## 4. 这次（10-25 ~ 10-28）加了什么

### 4.1 画画
- 工具 `qq_draw`，渲染器 `scripts/draw/render.py`（Python + Pillow，**没有出图模型**）。
- 四种画风：`crayon`（默认，线条抖/纸纹/微歪）、`picturebook`、`flat`、`pixel`。
- 图存 `data/drawings/`，标题/风格/来源记 `index.json`；归档逻辑在 `src/draw.js`。
- **画廊在 8899 面板第 ⑤ 块**（3210 那边的页签和 `gallery.html` 已按机主要求删掉了）。

### 4.2 自主活动扩展（`plugins/autonomous`）
动作白名单现在是：`share / diary / explore / finish / chat / draw / comment / search / publish`

| 动作 | 行为 | 护栏 |
|---|---|---|
| `share` | 发一段话（链接带不带由她定） | 安静时段、每轮额度、dryRun |
| `chat` | 主动说句话 | 同上 |
| `draw` | 画一张（4 种模板） | 分享走上面那套 |
| `comment` | 真想回一句才评 | 每天最多 3 条、<6 字判没话说、默认**不 @ 谁** |
| `search` | 记下关键词，**下次醒来先搜** | 6 小时过期 |
| `publish` | 小黑盒发帖（真机） | 每天 1 篇、正文 ≥20 字 |

**「记住了」闭环**：她日记里写 `心情：记住了`（或 `记下了/记上了`）→ 主进程写日记时**同步进经验库**。

### 4.3 三层记忆（这是这三天最大的改动）

```
核心规则：persona.roleText（人设）        → 每轮，永不裁剪
已学经验：data/learned.json（src/learned.js）→ 每轮挑 3~6 条（硬上限 15）
原始日记：E:\dsh\日记\每日\*.md            → 不自动进上下文，她主动翻才读
```

- **选取不是「最新 15 条」**：状态权重 + 相关性（关键词，含同义词归一化）+ 时效 打分。
- **状态机** `pending → verified → stable → archived`：
  - **她自己升不了级**（`setStatus` 里 `source !== 'owner'` 直接拒）
  - 再犯 → 合并时自动打回 `pending`，`corrections + 1`
  - 归档不删，强相关（≥3 个关键词重合）时能被捞回来
- **合并**：相似度 ≥0.28 且共享 ≥3 词 → 更新原条目，旧文本进 `history`（不覆盖）
- 机主入口：**8899 面板第 ⑥ 块**（确认/稳定/又犯了/编辑/删）、或 `node scripts/learned.mjs`

### 4.6 提示词指纹（10-29）

每轮 spawn DSH 之前往 `data/prompt-archive/turns.ndjson` 记一行，**只存哈希和 id，不存全文**：

| 字段 | 含义 |
|---|---|
| `persona` / `personaLen` | 人设文本哈希 + 字数（改一个字就变） |
| `promptJs` | 聊天侧 `src/prompt.js` 文件哈希 |
| `learnedTemplate` | 经验注入模板骨架哈希 |

## 6. 这次踩的坑（都真踩过）

1. **`PAGE` 是模板字符串**：里面写 `\n` 会被外层先解析成真实换行 → 面板脚本断行 → 启动自检中止（双击没反应）。必须用 `String.fromCharCode(10)`。**改 `web-panel-server.mjs` 后一定跑 `node test/web-panel-page-test.mjs`**。
2. `type: 'json'` 在 `defineTool` 的 parameters 里可用（无约束 JSON），靠 description 约束结构。
3. `defineTool` 的 `output.schema` 是 `additionalProperties:false`：返回值多一个字段就校验失败。
4. **Python 往管道 print 中文默认 GBK**，Node 按 UTF-8 读是问号 → `sys.stdout.reconfigure(encoding='utf-8')`。
5. 风格化/像素化必须作用在**最终尺寸**，且在**合成到不透明背景之后**（否则图形的 alpha 边缘会留幽灵环）。
6. 测试里不能用 `spawn` 的默认 pipe：DSH 沙箱报 `EPERM`，改用文件重定向（`stdio: [in, outFd, errFd]`）。
7. 测试别写死日期（`/^2026-10-25T/` 这种跨天就挂）。
8. ~~自检脚本直接 `import` 面板会把服务拉起来（占端口）~~ **10-28 已修**：`await main()` 现在包在
   `isMainModule` 里。之前 `test/web-panel-page-test.mjs` 每跑一次就凭空多一个面板（端口被占就
   顺延 8900、还是普通权限），日志里记的「连点三次快捷方式」其实就是它。仍要记住结论：**别在
   会被 import 的模块顶层无条件跑启动逻辑**。
9. 加提示词会撑爆 planner 的 900 token 预算测试：加规则必须同时压缩别处，**不能靠放宽测试**。
10. 小鲸鱼写日记会混用「记住了/记下了/记上了」——提取要认变体，只认「记住」会漏一半。
