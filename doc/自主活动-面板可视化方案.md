# 自主活动反馈可视化方案（2026-10-31 机主定稿）

> 来源：机主 2026-10-31 发来的补充方案。**这是设计稿，还没实现。**
> **依赖 `doc/自主活动-2.1方案.md`**：面板要展示的 `result` / `reflection` / `next`
> 得先由 2.1 的反馈闭环写出来，否则面板没有数据可显示。

## 目标

让老大能查看小鲸鱼每次自主活动结束后的**实际结果、选择理由、个人评价和后续想法**。

**不要求小鲸鱼主动向 QQ 汇报。**

## 一、记录反馈

在现有自主活动记录中保存：

| 字段 | 含义 |
|---|---|
| 时间 / 类别 / 来源 | 什么时候、什么动作、从哪个平台（bili / xhh / phone / draw） |
| 作品路径或内容链接 | 有产出时给路径/URL（画作 `data/drawings/…`、帖子链接） |
| `goal` | 活动目标 |
| `why` | 选择原因 |
| `result` | **程序确认**的实际结果（success / failed / skipped / no_output） |
| `reflection` | **模型**对经历的简短评价，**可以为空** |
| `next` | 可能想继续的方向，可以为空 |

- `reflection` 用自然语言，**不要求固定语气或正面评价**。
- **不额外调用模型**；现有调用拿不到真实反馈就留空，**不得编造**。

## 二、管理面板

在现有 **8899 面板**增加「自主活动」只读页面。

按时间展示活动卡片，包含：

- 活动类别和时间
- 实际完成情况（成功 / 失败 / 跳过 / 无成果）
- 图片预览或原帖链接
- 为什么选择这项活动（`why`）
- 她对这次经历的评价（`reflection`，空则不显示）
- 后续想法（`next`）

支持按**日期**、**活动类别**筛选。
无成果、未分享、无评价的活动**也要正确显示**。

## 三、数据一致性

- 复用现有 autonomous 日志与状态，**不新增第二套事实来源**；
- **程序确认的结果与模型评价分开存储**；
- 没看过作品时不能评价具体画面；
- 没看过帖子正文时不能声称读完了；
- 失败、跳过、无成果需要**明确区分**；
- 面板默认**只读**，不触发模型调用；
- 不影响现有日记、proactiveNote、`learned.json`；
- 保持原有日志的权限与隐私保护。

## 四、验收

1. 画画完成后可查看作品及相关反馈。
2. 浏览帖子后可查看标题、来源及评价。
3. 无成果活动可以展示。
4. 没有 `reflection` 时正常显示，**不自动补写**。
5. 没有实际看到内容时**不会生成虚假的具体评价**。
6. 不增加自主活动的模型调用上限。
7. 不影响既有反馈闭环和行为冷却。

### 实施顺序

1. **先做 2.1 的反馈字段**（`result`/`resultSummary`/`reflection`/`nextStatus`）——没有它，面板只能显示旧字段。
2. 再在 8899 加页面：读 `data/autonomous.json` 的 `history` + `data/autonomous-log.md`，**纯读**。
3. 卡片默认折叠，展开才显示 `why` / `reflection` / `next`。
4. 作品图用现有 `/drawing-image/`；帖子链接外跳。
5. 补测试：空 `reflection` 正常渲染、无成果活动正常渲染、不触发任何写操作。
