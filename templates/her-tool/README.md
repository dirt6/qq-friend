# 她自己写的小工具 · 模板

这是给小鲸鱼用的**技能模板**，本身不参与加载（在 `templates/` 下，不会被扫描）。

## 她想给自己加功能时怎么做

1. 复制整个 `templates/her-tool/` 到 `skills/her-<名字>/`
   - 例：想做水墨画 → `skills/her-ink/`
2. 改 `skill.json` 里的 `id`、`name`、`description`
3. 改 `index.js` 里 `registerTool` 的工具名和 `execute`
4. 存盘 → 机器人热重载会扫到（日志里一行「加载成功」）
5. 控制面板「她自己写的功能」那块会出现它

## 目录约定

| 放哪 | 会被怎么用 |
|---|---|
| `skills/her-*/` | 注册成**工具**，她自己能调用（像 `qq_draw` 那样） |
| `plugins/her-*/` | 注册 **hooks / providers**，在机器人流程里插一手（更底层） |

**只认 `her-` 前缀**：面板只展示这两个前缀下的东西，别改现有插件。

## 安全边界

- 写坏了**只影响它自己**：加载失败只打一行 warn，机器人照常跑。
- 不要直接发 QQ 消息，走 outbox（参考 `skills/diary`）。
- 不要改 `data/config.json` 和自己的人设——那是老大管的。
- 写完跟老大说一声，别偷着上。

## 一个真实的例子（水墨画）

她如果看到别人画的水墨画想学，可以做两件事：

1. **加画风**：改 `src/draw.js` 加一个 preset（这属于改核心代码，要老大同意）
2. **写工具**：在 `skills/her-ink/` 里写一个 `qq_ink` 工具，用 canvas/纯字符拼出水墨效果，产出图片路径

第二种更安全，也符合"给自己加能力"的意思。
