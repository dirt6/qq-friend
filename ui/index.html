记忆管理

        

          经验库的增删改查。所有写操作都会记入 logs/memory-write-audit.jsonl（记录结果，不只是请求）。
        


        


        

          
          
          
          
          
        

        


        


        

          这个页面做什么 / 不做什么
          

            
· 改状态：pending / verified / stable / archived。升级到 verified/stable 会以 source: 'owner' 记入，表示这是机主在界面上点的。

            
· 改内容：第一行替换原内容；其余行会新建为独立条目；多行时这条会被设回「待验证」。

            
· 归档过期：批量操作，把所有 stable 且超过 N 天没被用到的经验改为 archived（不是删除）。

            
· 删除：不可恢复。会先展示目标 ID + 状态 + 内容摘要，确认后才发送。

            
⚠️ 8899 面板上对应的四个按钮仍然是 403（1.5.6 有意退役）。这里是它们的正式去处。

          这个页面做什么 / 不做什么
          

            
· 启动/停止/重启机器人：走 explorer.exe 代启（降权标准做法）；停止只杀 lock 文件里的 PID。

            
· 启动 NapCat：Start-Process -Verb RunAs，和原来完全一致。

            
· 日志：只读两个固定文件，显式拒绝任何路径参数；命中凭据模式的值替换成 ***，整行是凭据的直接丢弃。

            
❌ 不提供：面板自重启（那是 8899 的事）、NapCat 停止、"一键全关"（那里按进程名杀 QQ）。

            
⚠️ 3210 目前没有认证（server.token 未配置），这个页面靠来源检查 + JSON 校验 + 明确确认兜底。不要把它当成权限系统。
